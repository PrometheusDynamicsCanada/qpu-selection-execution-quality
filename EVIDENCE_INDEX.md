# Evidence Index

This repository preserves the supplied evidence sets from the Fez, Kingston, Marrakesh, and multi-QPU experiment directories.

## Evidence directories

- `Fez/` — historical Fez scaling evidence
- `Kingston/` — historical Kingston scaling evidence
- `Marrakesh/` — historical Marrakesh scaling evidence
- `Fez_Marrakesh_Kingston/` — 20Q–22Q multi-QPU broadcast evidence
- `github_images/` — 20Q visual result screenshots

Each experiment directory contains the corresponding sanitized ledger, results CSV, verification CSV, evidence manifest, SHA-256 manifest, capture scripts, verifier, and IBM evidence ZIP packages.

For the 20Q–22Q broadcast set, the principal IBM job IDs are recorded in the directory's `public_evidence_ledger.json`, `master_results.csv`, `evidence_verification.csv`, and `evidence_manifest.json`.
